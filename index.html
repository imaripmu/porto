02 - Flagship Project · Final Thesis

Hybrid LSTM - RF Intrusion Detection for MQTT IoT Traffic

machine learning network security iot / mqtt flask api node-red

Final thesis - "Perancangan Sistem Deteksi Intrusi pada Trafik IoT Berbasis MQTT dan Node-RED Menggunakan Model Hybrid LSTM - Random Forest"

A DDoS detection system for IoT network traffic combining an LSTM encoder for temporal features with a Random Forest classifier for the final decision - validated with a leakage-free methodology that directly corrects a flaw in Ahmim et al. (2023, IEEE Access).

Why the methodology matters

  • Split-before-scaling - scaler fit only on training data, never on test/validation
  • Per-attack-type sequencing - prevents temporal contamination across files
  • Inference-time safety - infinite values zeroed, scaled values clipped to [0,1]

Smartphone Addiction Classifier

Tuned a Random Forest classifier to 93% accuracy on a 7,500-row behavioral dataset using systematic hyperparameter search. The project covers the full ML pipeline: exploratory data analysis, preprocessing, GridSearchCV tuning, and evaluation using accuracy, precision, recall, and F1-score.

The pipeline covered exploratory data analysis to understand feature distributions and class balance, preprocessing including categorical encoding and scaling where needed, and hyperparameter tuning via GridSearchCV across parameters such as number of estimators, max depth, and minimum samples per split. The tuned model was evaluated on a held-out test set using accuracy, precision, recall, and F1-score rather than accuracy alone.

The project was delivered as a single, reproducible Jupyter notebook designed to run cleanly in Google Colab or Kaggle, with every cell running top-to-bottom without hidden state and a self-contained evaluation section for independent verification.

What this demonstrates: this project sits at the "fundamentals" end of my ML work — the same split/scale/evaluate discipline shows up again, more rigorously, in the thesis. It's the smaller version of the same habit.
